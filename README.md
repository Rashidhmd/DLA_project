# DLA project - Brain Tumor Segmentation 

Fine-tuning **RF-DETR** (with segmentation head) to detect and delineate brain tumors in MRI scans, using a Roboflow dataset and the `supervision` library for visualization.

## Overview

This project fine-tunes [`RFDETRSegPreview`](https://github.com/roboflow/rf-detr) — a real-time detection transformer with instance segmentation — on a brain tumor MRI dataset. The goal is to produce per-instance segmentation masks that precisely outline tumor regions.

Key design choices:

- **Effective batch size of 16** via gradient accumulation (2 × 8 steps) to fit on a single GPU
- **EMA weights** for more stable checkpoints
- **Early stopping** to prevent overfitting on the small dataset
- **Cosine LR schedule with warm-up** in later experiments
- Multiple hyperparameter sweeps (Experiments 1–5) to find the best encoder/decoder learning-rate balance

## Model

**RF-DETR** is a real-time Detection Transformer developed by Roboflow. `RFDETRSegPreview` extends it with a segmentation head that produces polygon/mask outputs alongside bounding boxes.

Key parameters tuned across experiments:

| Parameter | Role |
|-----------|------|
| `lr` | Decoder learning rate |
| `lr_encoder` | Encoder (backbone) learning rate — typically kept lower |
| `resolution` | Input resolution (432 or 384 px) |
| `weight_decay` | L2 regularization |
| `lr_scheduler` | `cosine` decay or constant |
| `warmup_epochs` | Linear warm-up before the main schedule |
